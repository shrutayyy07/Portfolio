04

ECLSS anomaly detection

Team project

An AI-assisted system that detects anomalies early in life-support systems and raises diagnostic warnings.

Developing an AI-assisted anomaly detection system for Environmental Control and Life Support Systems (ECLSS), focusing on monitoring critical environmental parameters in spacecraft. The project aims to identify potential life-support failures, particularly ventilation malfunctions, before they become critical.

Implemented a physics-based air-cycle simulation incorporating gas laws, mass balance, and heat transfer to model variations in oxygen, carbon dioxide, cabin pressure, temperature, and humidity. Using Python, NumPy, Pandas, and SciPy, the system generates simulated sensor data under normal and faulty operating conditions. Integrated Scikit-learn’s Isolation Forest algorithm to detect abnormal sensor patterns and identify potential system malfunctions.

The proposed architecture includes sensor data simulation, anomaly detection, fault identification, and alert generation, with visualisation through Matplotlib. The project explores the application of machine learning and physics-based modelling for predictive monitoring, improving fault detection and supporting safer, more reliable spacecraft life-support operations.

05

CineMatch

Movie recommender · ML mini-project

A content-based recommender that returns the five most similar movies using k-nearest neighbours, with a dark-themed web interface.

scikit-learn · Python

Developing CineMatch, a machine learning-based movie recommendation system using K-Nearest Neighbours (KNN) and content-based filtering. The project uses the MovieLens 25M dataset from Kaggle to identify and recommend movies based on genre similarity, release year, and user ratings.

Implemented a feature engineering pipeline using 18 one-hot encoded genre features, along with scaled release year and Bayesian-shrunk average ratings, to improve recommendation relevance. Used Scikit-learn’s NearestNeighbors algorithm with Euclidean distance to identify the five most similar movies for a selected title.

Built a Flask-based backend API and an interactive frontend using HTML, CSS, and JavaScript, enabling users to search for movies, explore movie details, and receive personalised recommendations. The project demonstrates practical applications of machine learning, data preprocessing, feature engineering, similarity-based recommendation algorithms, and full-stack development.
